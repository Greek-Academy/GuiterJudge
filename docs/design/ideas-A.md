# 案 A: 世界観とビジュアル言語(A01〜A10)

視点: メタファー、色、タイポ、質感。どの案もアプリ全体に通すコンセプトとして書く。
現行(生成り #f9f9f7 + 青 #2a78d6 + 角丸カード、ライトのみ、説明文が多い)を見たうえで、共通の課題を 3 つに絞った。
- 1〜2 m 離れると数字の主従が読めない
- 「過去の自分」が表と矢印でしか出てこない
- 注意書きの文章が多く、世界観で意味を伝えられていない

各案とも、機能とデータは現行のまま引き継ぐ。

---

## A01 アンプパネル

- **一言コンセプト**: アプリ全体を 1 台の練習用アンプのフロントパネルにして、画面遷移を「つまみを回す/スイッチを倒す」操作として感じさせる。
- **なぜこの世界観か**: ギタリストが毎日いちばん長く見る「数値の出る物」はアンプとチューナーなので、ばらつきを VU メーターの針で読ませれば説明なしで「揺れ=不安定」が伝わる。
- **ビジュアル言語**
  - 色: トーレックス黒 `#1b1a18`、グリルクロス生成り `#d8ccb0`、クローム `#c9c9c4`、パイロットランプ赤 `#e0412b`、真空管の琥珀 `#f2a93b`
  - タイポ: パネル刻印風のコンデンスド・サンセリフ(Oswald / Bebas 系で英字ラベル、日本語は BIZ UDGothic Bold)。数値は 7 セグではなくメーター目盛り + 等幅数字 56〜96px
  - 形: 角丸は 4px 程度の金属プレート。1px のハイライトと下方向の短い影でビス止めした感じを出す。つまみは円形のタップ領域(64px 以上)
  - ライト/ダーク: ダーク基調(黒トーレックス)。ライトは「ブロンド・トーレックス」(`#e9dcc0` 地 + 茶文字)として同じ部品の色替えで用意する
- **情報設計とナビゲーション**
  - ホームは「チャンネル切替」。各スレッドを入力チャンネルに見立て、今日の一本は常に CH1 に立ち上がっている
  - 主導線: 開く→CH1 の大きな赤い REC スイッチ→録音後はメーターが振れて結果パネルへ
  - タブ無し。上端のスライドスイッチで「練習 / 記録 / 設定」の 3 モード
- **主要 3 画面のスケッチ**
```
ホーム
┌───────────────────────────────┐
│ ◉ POWER        GUITAR-DIAG    │
│ ░░░░░░░░ grill cloth ░░░░░░░░ │
│ ░ CH1 今日の一本             ░ │
│ ░ 16分オルタネイト Am 5-8f   ░ │
│ ░  前回 13ms  ♩58            ░ │
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │
│  ( ) ( ) ( )      ● ● ● ● ○   │
│  TEMPO CNT MIN     STABILITY  │
│  [    ●  REC  (赤ランプ)   ]  │
│  CH2 クロマ ▮▮▯▯▯  CH3 G-C-D  │
└───────────────────────────────┘
録音中
┌───────────────────────────────┐
│ ● REC  ランプ点滅   00:14     │
│      ╭───── VU ─────╮         │
│      │ -20 -10  0 +3│         │
│      │      ╲       │ ← 入力  │
│      ╰──────────────╯         │
│   ♩=58   1 . 2 . 3 . [4]      │
│   (拍ごとにランプが琥珀に点灯)  │
│                               │
│   [      ■  STOP       ]      │
└───────────────────────────────┘
診断結果
┌───────────────────────────────┐
│  前回 ◀━━━━━━━━━━━▶ 今回      │
│   ╭─ ばらつき ─╮ ╭─ 一致率 ─╮ │
│   │  ╲ 14→13  │ │  ╱ 83→92 │ │
│   ╰──── ms ───╯ ╰──── % ────╯ │
│   弾き忘れ/余分 [6]→[2]        │
│   発見: いちばん小さい値と横ばい │
│   MODE ○直前 ●最安定 ○お手本  │
│   ▭▭▭ ピアノロール(琥珀の点) ▭▭ │
│   [   ● もう 1 回    ][一覧]   │
└───────────────────────────────┘
```
- **体験の核**: 録音を止めた直後、2 本のメーター針が「前回の位置」から「今回の位置」へ物理的に振れて止まる 1 秒。
- **練習中の配慮**: REC/STOP は画面下 1/3 を占める巨大スイッチにする。カウントインは拍ランプの点灯で示し、2 m 先からでも色で拍が分かる。録音中はメーター以外の要素をすべて消す。
- **リスク・弱点**: スキューモーフィズムが古びやすい。つまみ UI はスクリーンリーダーで扱いにくく、スライダーの ARIA 化が要る。細部を作り込むほど重くなる。
- **実装コスト**: M(CSS グラデーションと SVG のメーター部品が中心。画像素材は不要)

## A02 練習手帳

- **一言コンセプト**: アプリを 1 冊の方眼の練習ノートにする。スレッドは見開きのページ、テイクは日付入りの書き込みで、過去の自分はページの前のほうに「残っている」。
- **なぜこの世界観か**: 独学ギタリストが昔から使ってきた記録媒体は紙のノートで、「空白の日があってもページは責めない」という性質がこのアプリの思想に合う。
- **ビジュアル言語**
  - 色: 方眼紙 `#fbf8f1`、方眼罫 `#d9e3ea`、鉛筆グラファイト `#3a3a3a`、赤ペン `#c8402f`、付箋イエロー `#f6d860`
  - タイポ: 見出しは手書き風の丸ゴシック(Zen Maru Gothic / Klee One)。数値は鉛筆のまま太めのヒューマニスト(Inter Tight 相当)48〜80px。注記は小さな手書き体
  - 形: 角丸なし。紙の端に 1px の影、付箋は 2° 傾ける。線は方眼に揃えた 8px グリッド。チェックマークと丸囲みは SVG の手描きストローク
  - ライト/ダーク: ライト基調。ダークは「夜のノート」(`#23252b` の黒表紙に、白い方眼 `#3a3f47` とチョーク色の文字)
- **情報設計とナビゲーション**
  - ホーム = 目次ページ。今日の一本は目次に貼った付箋として出す
  - スレッド詳細 = 見開きの左ページ(推移グラフを方眼にプロット)と右ページ(今日の書き込み)。スマホでは横スワイプで左右のページを行き来する
  - 主導線: 付箋をタップ→ページが開く→「録る」栞→書き込み(診断)が追記される
  - タブ無し。上端の小口インデックス(色の見出しタブ)でスレッドを切り替える
- **主要 3 画面のスケッチ**
```
ホーム(目次)
┌───────────────────────────────┐
│ ┊ 練習帳 No.3        9/23(火) │
│ ┊┌──────────────┐ ←付箋       │
│ ┊│今日の一本     │            │
│ ┊│16分オルタネイト│  前回13ms  │
│ ┊│  ✎ 録る       │            │
│ ┊└──────────────┘            │
│ ┊ 目次                        │
│ ┊ p.12 クロマチック ●●○○○  2日前│
│ ┊ p.18 G-C-D-G   ●●○○○   昨日 │
│ ┊ p.24 F→B♭      ●●●○○   昨日 │
│ ┊ (空いた日は余白のまま)        │
└───────────────────────────────┘
録音中
┌───────────────────────────────┐
│ 9/23 21:40  take 7            │
│ ─────────────────────────────  │
│   ♩=58      ① ② ③ ④          │
│                               │
│   ~~~~~~~ 鉛筆で波形が ~~~~~   │
│   ~~~~~~~ 書かれていく ~~~~~   │
│                               │
│         ◯ 00:12               │
│   [       書き終える      ]    │
└───────────────────────────────┘
診断結果(書き込み)
┌───────────────────────────────┐
│ 9/23 take 7           p.24    │
│  ばらつき  14 → (13) ms  △    │
│  一致率    83 → (92) %   ◯    │
│  弾き忘れ   6 → ( 2)     ◯    │
│  ┌付箋──────────────────┐     │
│  │発見: いちばん小さい値と │     │
│  │横ばい                  │     │
│  └──────────────────────┘     │
│  方眼に ●●●●○ 格子ばらつき     │
│  [ ✎ もう 1 回 ]   [目次へ]    │
└───────────────────────────────┘
```
- **体験の核**: 診断を開いたとき、今回の数字に赤ペンの丸がスッと描かれ、同じページの少し上に前回の自分の数字が鉛筆で残っているのが見える瞬間。
- **練習中の配慮**: 録音中は方眼を薄くして、拍番号 ①〜④ を 96px で出す。「書き終える」ボタンは下半分いっぱいに取る。手書き体は注記だけに使い、数値には使わない(可読性のため)。
- **リスク・弱点**: 可愛くなりすぎて「計測アプリ」としての信頼感が落ちるおそれがある。手書きフォントは日本語だと容量が大きく、PWA の初回ロードに響く。
- **実装コスト**: M(方眼は CSS の background-image だけで描ける。手描きストロークは SVG 数種)

## A03 五線紙とインク

- **一言コンセプト**: 画面を上質な五線紙に見立て、テイクの音は万年筆のインクの点として五線上に置く。一貫性は「インクの滲みの少なさ」として見える。
- **なぜこの世界観か**: 楽譜お手本(MusicXML)と自分の演奏を同じ紙面に重ねられるので、「楽譜にどれだけ揃って置けたか」がいちばん自然な比喩になる。
- **ビジュアル言語**
  - 色: 楽譜用紙のクリーム `#f7f2e7`、五線のセピア `#b9ab92`、ブルーブラックのインク `#1f2a44`、朱の校正色 `#b5452f`、前回の自分に使う薄墨 `#8e97a8`
  - タイポ: 見出しと数値はディドーン系セリフ(Bodoni Moda / 游明朝 Demibold)。数値は 64〜120px のオールドスタイル数字。本文は明朝 15px
  - 形: 角丸なし、影なし。罫線は 0.5〜1px。区切りは五線の 5 本線そのものを使う
  - ライト/ダーク: ライト基調。ダークは「夜の写譜」(`#14161c` の紙に淡い金の五線 `#6b6250` + 象牙色のインク `#efe6d2`)
- **情報設計とナビゲーション**
  - ホーム = 楽譜帳の表紙と、スレッドごとの「段」。1 スレッドが 1 段で、右端に直近テイクの小節が並ぶ
  - 詳細 = 1 曲分の総譜。上の段がお手本(または前回)、下の段が今回で、縦に揃えて読む
  - 主導線: 段をタップ→総譜→下端の「録る」→新しい段が一番下に足される
  - タブ無し
- **主要 3 画面のスケッチ**
```
ホーム
┌───────────────────────────────┐
│   Practice Score   9.23       │
│                               │
│ 今日の一本                     │
│ 𝄞━━●━━●━●━━━●━━●━━━━━━━━━━━  │
│  16分オルタネイト   前回 13ms  │
│         [ 録る ]              │
│ ─────────────────────────────  │
│ 𝄞━●━●━●━●━━  クロマチック 2日前│
│ 𝄞━━●━━━●━━━  G-C-D-G    昨日  │
│ 𝄞━━●●━━●●━━  F→B♭       昨日  │
└───────────────────────────────┘
録音中
┌───────────────────────────────┐
│                               │
│      ♩ = 58                   │
│   ━━━━━━━━━━━━━━━━━━━━━━━━━   │
│   ━━●━━━━●━━━━●━━━━○━━━━━━━   │
│   ━━━━━━━━━━━━━━━━━━━━━━━━━   │
│   (インクの点が拍位置に落ちる)   │
│                               │
│          1  2  3 [4]          │
│   [          止める        ]   │
└───────────────────────────────┘
診断結果
┌───────────────────────────────┐
│ お手本 ━●━━●━━●━━●━━●━━━ (薄墨) │
│ 今回   ━●━━●━●━━━●━━●━━━ (藍)  │
│              ↑朱の小さな印      │
│                               │
│   13         ms               │
│   ばらつき(前回 14、横ばい)     │
│   一致率 92  弾き忘れ/余分 2    │
│   発見 いちばん小さい値と横ばい │
│   [ もう 1 回 ]  [ 楽譜帳へ ]   │
└───────────────────────────────┘
```
- **体験の核**: 前回(薄墨)と今回(藍)の音符が縦に重なり、ズレた音にだけ朱の小さな印がつく。音楽の紙面の上で「揃ってきた」ことが見える瞬間。
- **練習中の配慮**: 録音中は五線を 3 倍に拡大し、拍位置だけを示す。1〜2 m 先から見るのは五線の上の「次の拍の点滅」だけで足りる。ボタンは紙面の下端いっぱい。
- **リスク・弱点**: 楽譜を読まないギタリスト(TAB 派)には敷居が高く感じられる。単音フレーズ以外、特に和音やストロークでは五線の比喩が弱い(コードタイムラインは別の見せ方が要る)。
- **実装コスト**: M〜L(ピアノロールを五線表示に作り替える部分が重い。見た目だけなら M)

## A04 深夜の自室スタジオ

- **一言コンセプト**: 夜、部屋の明かりを落としてスタンドライト 1 灯で弾くときの空気をそのまま UI にする。暗い部屋に浮かぶのは「今日の一本」と REC ランプだけ。
- **なぜこの世界観か**: 社会人の独学練習は夜に 5〜15 分という条件が多いので、暗い部屋で眩しくなく、譜面台の上から一番大事な 1 行だけが光る画面が実際の利用状況に合う。
- **ビジュアル言語**
  - 色: 部屋の闇 `#0e0f12`、壁の反射 `#1c1e24`、スタンドライトの暖色 `#ffb862`、ON AIR の赤 `#ff4a3d`、読み物用のオフホワイト `#e8e4dc`
  - タイポ: 幾何学サンセリフ(Manrope / Noto Sans JP Medium)。主要数値は 88〜140px の細め(Light)で、光る文字として扱う。ラベルは 13px の字間を広げたキャプス
  - 形: 面は角丸 20px。枠線は使わず、明るさの差だけで面を分ける。ライトが当たった面には中心から外へ弱い放射グラデーション
  - ライト/ダーク: ダークが既定。ライトは「昼のスタジオ」(`#f2efe9` + 暖色アクセント)として従に置く
- **情報設計とナビゲーション**
  - ホーム = 暗い部屋に今日の一本だけが灯っている。他のスレッドは下へスワイプすると「棚」として薄く出てくる
  - 主導線: 開く→灯っている一本をタップ→ON AIR ランプ→結果が同じ光の中に出る
  - タブ無し。画面は「灯り(今)」「棚(一覧)」「ログ(推移)」の 3 層を縦スクロールで行き来する
- **主要 3 画面のスケッチ**
```
ホーム
┌───────────────────────────────┐
│                               │
│            ·  ·  ·            │
│        ( 暖色の光だまり )       │
│     16分のオルタネイト          │
│     Am ペンタ 5-8f             │
│        前回  13 ms             │
│                               │
│         ( ●  録る )            │
│                               │
│ ─ 棚 ─────────────────── ↓    │
│ クロマチック ▪▪▫▫▫  G-C-D ▪▪▫▫▫ │
└───────────────────────────────┘
録音中
┌───────────────────────────────┐
│ ┌───────────┐                 │
│ │ ● ON AIR  │ (赤い光が滲む)   │
│ └───────────┘                 │
│                               │
│            3                  │
│      (カウントイン 140px)       │
│                               │
│   ·   ·   ●   ·   (拍の光点)   │
│                               │
│      (  ■ 止める  )            │
└───────────────────────────────┘
診断結果
┌───────────────────────────────┐
│   前回の自分    今夜            │
│     14    →    13  ms         │
│   (薄い灰)     (暖色で灯る)     │
│   一致率  83 → 92              │
│   弾き忘れ  6 → 2              │
│   ─────────────────            │
│   発見: いちばん小さい値と横ばい │
│   ▒▒ ピアノロール(光の粒) ▒▒    │
│                               │
│   ( ● もう 1 回 )   一覧        │
└───────────────────────────────┘
```
- **体験の核**: 結果が出たとき、前回の数字は灰色のまま、今夜の数字だけが暖色でふわっと灯る瞬間。勝ち負けではなく「今夜の自分」に光が当たる。
- **練習中の配慮**: 暗い部屋で画面が眩しくならない。カウントインと拍の光点は 2 m 先でも周辺視野で読める。操作対象は中央の丸ボタン 1 つ。Wake Lock で消灯を防ぐ。
- **リスク・弱点**: 昼間や明るい部屋ではコントラストが足りなく感じられる。ダーク既定は、色覚やロービジョンの人向けのコントラスト検証を厳密にやる必要がある。雰囲気に寄りすぎて情報量が減りやすい。
- **実装コスト**: S〜M(CSS 変数の色替えと放射グラデーションが中心で、現行構造を活かせる)

## A05 ひとつの数字

- **一言コンセプト**: どの画面も、主役は数字 1 つだけにする。今日の数字、前回の数字、その差。他の情報はすべて、タップして「めくる」まで出てこない。
- **なぜこの世界観か**: 一貫性は「ばらつき ms」という 1 つの量にまとめられるので、その数字を譜面台の向こうからでも読める大きさで置くことが、診断を一目で分からせる最短の道になる。
- **ビジュアル言語**
  - 色: 紙白 `#ffffff`、墨 `#111111`、中間灰 `#9a9a9a`(前回の自分用)、1 色だけのアクセント `#0057ff`(今回の数字だけに使う)
  - タイポ: ネオグロテスク(Inter Display / Helvetica Now 系)。主数字は 160〜220px の Tabular Figures、ラベルは 12px。中間のサイズは使わない(極端な 2 段だけ)
  - 形: 角丸・影・枠線なし。余白と文字サイズだけで構造を作る。区切りは 1px の罫 1 本まで
  - ライト/ダーク: 完全に対称な 2 モード(白地に黒 / 黒地に白)。アクセントの青だけを `#5c8dff` に明るくする
- **情報設計とナビゲーション**
  - 1 画面 1 数字のカードを縦にページング(scroll-snap)する。ホームは「今日の一本の前回値」1 枚
  - 主導線: 数字をタップ=録る。結果=新しい数字 1 枚。上にスワイプすると一致率、弾き忘れ、ピアノロールの順にめくれる

```
- **体験の核**: 録音を終えると、木口のいちばん外に新しい輪がすっと描かれる。1 つ内側の前回の輪と見比べて「今日は輪が丸い」と感じる瞬間。
- **練習中の配慮**: 録音中は同心円 1 つと拍の数字だけを出す。円が拍ごとに一周するので、視線を合わせなくても周辺視野でテンポが感じられる。ボタンは下端いっぱい。
- **リスク・弱点**: 「輪の歪み」が統計量(標準偏差)の直感的な写像として正しいか検証が要る。誤読されるおそれがある。テイク数が 50 を超えると輪が細かすぎて見えなくなるので、日単位に束ねる必要がある。
- **実装コスト**: M(SVG で同心の path を生成する。データからの形状生成とアニメーションが主な工数)

## A10 ゴースト・ラップ(陸上の計測)

- **一言コンセプト**: 陸上トラックのラップ計測盤とゴーストランナーの比喩を使う。競う相手は常に「前回の自分のゴースト」だけで、テイクは 1 本のラップとして記録盤に並ぶ。
- **なぜこの世界観か**: 陸上の自己ベスト文化は他人ではなく自分の過去の記録と向き合うもので、ゴースト(半透明の過去の自分)と並走する見せ方は「過去の自分と比べる」を最も身体的に伝えられる。
- **ビジュアル言語**
  - 色: トラックのレンガ色 `#c2553a`、レーンの白線 `#f6f3ee`、計測盤の黒 `#121417`、LED タイマーの黄 `#ffd400`、ゴーストの半透明の水色 `#8fd3ff`(不透明度 50%)
  - タイポ: 計測盤風のコンデンスド・ボールド(Barlow Condensed / Oswald)。数値は 96〜160px の等幅数字。和文はゴシックの太め
  - 形: 角はほぼ直角(2px)。レーン線(平行な白線)が画面の基本の区切り。影は使わず、太い帯と細い白線だけ
  - ライト/ダーク: ダーク(夜のナイター照明の計測盤)が既定。ライトは「昼のトラック」(`#f6f3ee` 地 + レンガ色の帯)
- **情報設計とナビゲーション**
  - ホーム = 記録盤。今日の一本が第 1 レーンで、自分の前回ラップ(ゴースト)が隣に表示される。他のスレッドは下のレーン
  - 詳細 = 1 レーンのラップ表(日付ごとの記録)と推移
  - 診断 = 2 レーン並走図。上のレーンがゴースト(前回 / 最安定 / お手本を切り替え)、下のレーンが今回。音符を走者の足跡として並べる
  - 主導線: レーンをタップ→「ON YOUR MARKS」のカウントイン→ラップ終了→並走図
  - タブ無し。「勝敗」は 3 項目の小さな ◯/△ に留め、合計勝数は出さない
- **主要 3 画面のスケッチ**
```

- **実装コスト**: M(並走図は既存のピアノロールのデータを 2 レーンの横帯に描き直せば作れる)
