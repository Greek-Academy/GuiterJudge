# ideas-D(再コンペ): 過去の自分と成長の手触り(D01〜D10)

担当視点: **1 週間後・1 か月後・半年後に見返したくなる記録**。過去の自分との比較の見せ方、「横ばい」を責めずに楽しく見せる方法、ギタリストの文脈(フレーズ、曲、指板、音)。

前提: 共通ブリーフ(r2/brief.md)の書式に従う。前回の最終候補 F1〜F4 と、前回 1 次審査の D07 フレーズの地層・E05 弾き込み・E08 持ち曲帳・A08 月刊エディトリアル・D04 拍の時計と近い要素を使う案は、何を変えたかを各案に書いた。横ばいの幅は habit/verdict.ts の既存値(ばらつき 4ms / 一致率 5pt / 弾き忘れ・余分 1 個)をそのまま使い、全案に前回の共通改善「ノイズの帯」を敷く前提とする。

---

## 0. 「毎日触りたくならない」原因(この視点から見た 3 つ)

現行 UI(ホームの「今日の一本」カード、VersusCard の対戦カード、ScoreTrend、安定ゲージ)と、前回の最終候補 F1〜F4 を見て、過去の自分と成長の手触りの観点から挙げる。

1. **過去の自分が「直前の 1 個の数字」にしか居ない。** ホームに出る過去は「前回 9/22: ばらつき 13ms」の 1 行だけで、1 週間前・1 か月前・最初の日の自分はスレッド詳細の奥にある推移グラフまで行かないと会えない。F1「ひとつだけ」はこれをさらに削り、灰の前回値 1 つにした。直前比しかないと、比べられる時間の幅がいつも 1 日しかない。上達は数週間単位でしか現れないので、毎日見る画面にはほぼ毎日「差が無い」が出る。**時間のスケールを選べない**ことが、見返したくならない一番の原因。
2. **「横ばい」が「何も起きなかった日」として出る。** 一貫性の指標を正直に扱うと、判定の大半は横ばいになる(それ自体は正しい)。ところが現行は VersusCard が「勝ち / 引き分け / 負け」「3 連敗」の語彙で組まれていて、横ばいは灰色の「引き分け」として置かれるだけ。一貫性を測るアプリなのに、「前と同じに弾けた」ことが何のご褒美にもなっていない。Duolingo が毎回のレッスン終わりを必ず祝うのに対して、このアプリは大半の日を無言で終わらせている。
3. **成長が「手で触れる形」をしていない。ギタリストの持ち物(音・フレーズ・指板・テンポ)に翻訳されていない。** テイクの音声は Blob として全部保存されているのに、過去の自分の **音** は主役になっていない。記録はスレッド名の文字列と ms の数字で、指板のどこを弾いてきたか、どのテンポなら落ち着くか、どの癖が消えたか、といったギタリストが自分で語れる言葉になっていない。F3 の持ち曲帳は長期の手触りを「一覧」で作ったが、一覧は開いた瞬間の反応(生き物っぽさ)が弱い。記録がたまるほど画面が変わる、という積み上がりの手触りが無い。

この 3 つに対して、10 案はそれぞれ別の軸で答える: **音で会う**(D01, D10)、**場所で積む**(D02)、**時間の幅を選ぶ**(D04)、**形で残す**(D05)、**節目で束ねる**(D06)、**再訪する**(D03)、**癖・テンポというギタリストの言葉にする**(D07, D08)、**過去から声をかけられる**(D09)。

## D01 あの日のテイク(聴き返しのタイムカプセル)

**一言コンセプト**: アプリを開くと、1 週間前・1 か月前の「あの日の自分」の演奏が 1 枚のレコードとして待っていて、タップで 8 秒聴いてから今日の 1 本を録る。

**毎日触りたくなる仕掛け**
- Duolingo の「開いた瞬間にやることが決まっている」と「小さなご褒美」を、**過去の自分の音** に翻訳する。数字より先に音で会うので、横ばいかどうかと関係なく毎日「聴く楽しみ」がある。
- ホームの主役は「今日の一本」+「◯日前のあなた」のレコード 1 枚。候補は同じスレッドの 7 日前・30 日前・初日のテイクから、その日の日付で巡回して選ぶ(保存なしで決まる)。
- 聴き終わると「今日の 1 本を録る」がそのまま大きくなる。録り終えたら、あの日のテイクと今日のテイクを **交互に 2 回ずつ** 再生する「聴き比べ」が 1 タップで出る(前回 D08 聴き比べのステレオの簡易版。時間伸縮はしない)。
- 1 日目: 比べる過去が無いので「最初の 1 枚」をプレスする演出(レーベルに日付が刻まれる)。1 週間後: 初めて「7 日前のあなた」が現れる。1 か月後: 「30 日前」と「初日」が選べるようになり、手元のレコード棚が厚くなる。
- 解決済みスレッドのテイクも棚に残り、たまに「3 か月前に解決したフレーズ」が出てくる。

**ビジュアル言語**
- 色: 面 `#F4EFE6`(dark `#16130F`)、レーベル朱 `#D9573B`、盤の黒 `#1D1B19`(dark では `#2A2621`)、今日の青 `#2F6FD6`、過去の灰 `#8C857A`
- タイポ: 本文 Noto Sans JP、日付と「◯日前」は等幅数字の太字 32〜48px。レーベルの文字だけ Zen Maru Gothic
- 形: 円(レコード)と帯(棚)。カードの角丸 20px
- モーション: タップで盤が 1 回転してから音が出る(0.4 秒)。再生中は溝がゆっくり回る(prefers-reduced-motion では静止し、進捗は円周の弧で出す)
- ライト/ダーク: 両対応。ダークでは盤の艶を弱くして面と同化させない

**情報設計とナビゲーション**
- 3 層: ホーム(今日の一本 + あの日のレコード)/ 録音・診断(1 画面の上下)/ 棚(スレッドごとのレコード列 = テイク履歴)。
- 主導線: 開く → あの日を聴く(任意、飛ばせる)→ 録る → 診断 → 聴き比べ(任意)。
- 棚は既存のテイク履歴と推移グラフを置き換えず、その上に「盤」として重ねる。

**主要 3 画面のスケッチ**

ホーム

```
┌──────────────────────────────┐
│ 9月30日(水)                  │
│                              │
│   ◯日前のあなた              │
│      ╭──────────╮            │
│     │  ╭────╮   │  30日前    │
│     │  │ 8/31│  │  16分の    │
│     │  ╰────╯   │  オルタネイト│
│      ╰──────────╯  ♩=58      │
│        ▶ 8 秒聴く            │
│                              │
│ ┌──────────────────────────┐ │
│ │   ●  今日の 1 本を録る   │ │
│ └──────────────────────────┘ │
│  棚を見る  ·  別のフレーズ    │
└──────────────────────────────┘
```

録音中

```
│                              │

│                              │
```

**体験の核**: 30 日前の自分の音が鳴った 3 秒後に「あ、こんなだったか」と思う瞬間。数字が横ばいでも、耳で違いに気づくことがある(気づかなくても、それは「揃っている」ということ)。

**練習中の配慮**: 聴き返しは録音の前後だけで、録音中は過去の音も図も出さない(ゴーストで演奏が歪むのを避ける)。再生ボタンは画面幅いっぱい・高さ 72px。Wake Lock。

**思想との衝突**: 「◯日前」の選び方がランダムっぽいとガチャに見える。日付で決定的に巡回させ、選び直しも 1 タップで自由にする。

**リスク・弱点**: 音声の頭出し(無音の前置き)を切らないと 8 秒が無音で終わる。analysisOffsetMs を使って最初の音の 0.3 秒前から再生する。ストレージが増えるが、既に全テイクの Blob を保存しているので追加は無い。

**実装コスト**: M(再生 UI、頭出し、交互再生。解析の追加は無し)

## D02 指板の足あと

**一言コンセプト**: ホームは 1 本のギターの指板で、これまでに弾き込んできたフレーズがその場所に灯り、弾くたびに足あとが濃くなる。

**毎日触りたくなる仕掛け**
- Duolingo の「進んだ分だけ地図が埋まる」を、ギタリストが一番よく知っている地図 = **指板** に翻訳する。
- スレッドは指板上の「ポジション帯」(例: 5〜8 フレット、開放〜3 フレット)に置かれる。帯はスレッド作成時に選ぶ(既定はテイクの音域から推定した候補を提示し、本人が確定。弦の推定はしない)。
- 足あとの濃さは **弾いた日数** で決まり、成績(ms)では変えない。数字は帯をタップして初めて出る。量が正義にならないよう、濃さは 7 日で頭打ちにする(前回 E05 弾き込みの「本数が主役」への減点に対する修正)。
- 解決済みのフレーズは帯の上に小さなドット(インレイ)として残る。半年後に指板を見ると、どのポジションで何を身につけたかが模様になっている。
- 1 日目: 空の指板に最初の帯が 1 本灯る。1 週間後: 帯が濃くなり、隣のポジションに 2 本目を置きたくなる。1 か月後: インレイが増え、「12 フレットより上はまだ何も無い」という余白が次の練習の誘いになる(責めない。余白は明るい木目のまま)。

**ビジュアル言語**
- 色: 指板のローズウッド `#3B2A22`(light でも指板だけは暗い)、面 `#F6F1EA`(dark `#121010`)、足あと琥珀 `#E8A33D`、今日の帯 `#5FB3F0`、インレイの貝 `#EDE6D6`
- タイポ: Noto Sans JP、フレット番号は等幅数字 14px、スレッド名 18px 太字
- 形: 横長の指板を縦持ちでは縦に回転して置く(ヘッドが上)。フレット線、弦 6 本、インレイ
- モーション: 録音後に帯が一段濃くなるとき、琥珀の光が弦に沿って 0.5 秒流れる
- ライト/ダーク: 指板は両モードで暗い。周囲の面だけ切り替わる

**情報設計とナビゲーション**
- ホーム = 指板(スクロールでフレットを上下)。帯をタップ → スレッドの下シート(今日の一本はシートが最初から半分開いている)。
- 曲通しと和音の練習は指板の横の「ヘッド側の棚」に置く(ポジションを持たないため)。
- 主導線: 開く → 今日の帯(光っている)をタップ → 録る → 診断 → 指板に戻ると帯が濃くなっている。

**主要 3 画面のスケッチ**

ホーム
```
┌──────────────────────────────┐
│  ヘッド  [曲通し] [和音]      │
│ ═══════════════════ 0        │
│ │ │ │ │ │ │                  │
│ ───────────────── 3  ░ クロマ │
│ │ │ │ │ │ │          チック  │
│ ───────────────── 5 ▓▓▓ 今日 │
│ │▓│▓│▓│▓│▓│▓│      Amペンタ  │
│ ───────────────── 8 ▓▓▓ 16分 │
│ │ │ │ ◆ │ │ │ 9 (解決済み) │
│ ───────────────── 12  ◆◆     │
│ │ │ │ │ │ │    (まだ何も無い)│
│ ┌──────────────────────────┐ │
│ │ ● 5〜8 フレットを録る    │ │
│ └──────────────────────────┘ │

```

```
│                              │
│  ─── 5 ───────────────       │
```

```
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

**体験の核**: 録り終えて指板に戻ると、今日の帯が一段濃くなっていて、光が弦を流れる瞬間。数字の良し悪しと関係なく「ここを弾いた」が指板に刻まれる。

**練習中の配慮**: 録音中の指板は静止画(光らせない)。ポジション名「5〜8 フレット」を 40px で出し、譜面台から「いま何の練習か」が読める。

**思想との衝突**: 弾いた日数で濃くなるのは「量」の可視化で、ストリークに近い。連続性は見ない(飛び飛びでも同じだけ濃くなる)、頭打ちがある、空白で薄くならない、の 3 点で区別する。

**リスク・弱点**: ポジションの概念が無いフレーズ(開放弦を含む広い音域、スライドで移動するもの)は帯が長くなりすぎる。「複数帯」か「ヘッド側の棚」に逃がす。変則調弦(tuningLowest)で音域推定がずれる。

**実装コスト**: M(指板 SVG、帯の配置、スレッドにポジションの属性を追加)

## D03 再訪(むかしのフレーズに寄り道する日)

**一言コンセプト**: 練習の最初の 1 本は、数日〜数週間前に手を離したフレーズへの「寄り道」で、そのフレーズの初日の自分と今日の自分が並ぶ。

**毎日触りたくなる仕掛け**
- Duolingo の「復習(忘れかけた単語が戻ってくる)」を、**間隔反復による再訪** に翻訳する。忘れかけのフレーズを 1 本だけ弾くのは短く(1 分)、区切りが明快で、ウォームアップとして自然。
- 再訪の相手は、アクティブの「冷えた」スレッドと解決済みスレッドから、最後に触ってから 3 日・7 日・21 日・60 日の間隔で順番に回ってくる。
- 再訪の診断は **直前比ではなく初日比** を既定にする。数日空けたフレーズは直前比では落ちることが多いが、初日と比べると差が出ていることが多い。どちらの比較でも帯の中なら「横ばい」と書く。
- 「寄り道」の後に本題の「今日の一本」へ進む 2 段構成。寄り道は飛ばせる(飛ばしても何も起きない)。
- 1 日目: 寄り道は出ない(相手がいない)。1 週間後: 最初の寄り道が 3 日前のフレーズで現れる。1 か月後: 解決済みのフレーズが初めて戻ってきて、「解決した日の自分」とも並ぶ。半年後: 解決済みが 60 日おきに回ってくる。

前回 E08 持ち曲帳(F3 の核)との違い: 持ち曲帳は解決済みを「一覧」で残した。本案は一覧を作らず、**向こうから日替わりで 1 本やってくる** 形にして、開いた瞬間にやることを決めている。

**ビジュアル言語**
- 色: 面 `#F2F5F1`(dark `#0F1412`)、寄り道の緑 `#3E9B6E`、今日の本題の青 `#2B6FD1`、初日のセピア `#A88A5C`、補助の灰 `#86898A`
- タイポ: Noto Sans JP。「◯日ぶり」は 56px 太字。日付は等幅数字
- 形: 道(縦の 1 本線)に寄り道の分岐が 1 本出ている図をホームの骨格にする。角丸 16px
- モーション: 寄り道を終えると分岐が本線に合流するアニメーション(0.6 秒)
- ライト/ダーク: 両対応

**情報設計とナビゲーション**
- ホーム = 今日の道(寄り道 → 本題の 2 ステップ)。下に全スレッド一覧への入口。
- 寄り道の診断は 3 点比較(初日 / 最後に触った日 / 今日)。本題の診断は現行どおり直前比が既定。
- 主導線: 開く → 寄り道を 1 本録る(または飛ばす)→ 本題を録る → 今日のまとめ。

**主要 3 画面のスケッチ**

**体験の核**: 12 日ぶりに弾いたのに「最後の日と横ばい」と出る瞬間。忘れていなかったことが、断定せずに分かる。横ばいがそのまま「残っていた」という良い知らせになる。

**練習中の配慮**: 寄り道は 1 分以内の短いテイク想定。録音画面の見出しに「寄り道」「本題」を 32px で出し、どちらを録っているか譜面台から分かる。寄り道 → 本題の切り替えは録り終えた画面の大ボタン 1 つ。

**思想との衝突**: 間隔反復の予定が「課題」に見える恐れ。「◯日遅れ」は出さず、予定日を過ぎていても「◯日ぶり」と書くだけにする。

**リスク・弱点**: 再訪で落ちたときの見せ方。初日比では落ちにくいが、落ちた場合は「最後の日より帯の外で大きい」と方向だけ書き、責めない一文(「久しぶりの 1 本はそうなりやすいです」は断定なので使わない)を文言ルールで管理する。

**実装コスト**: S〜M(選び方の純関数、3 点比較の表示。比較は既存の compareMode を拡張して初日のテイクを指定)

## D04 時間の望遠鏡

**一言コンセプト**: 診断の比較相手を「昨日・1 週間前・1 か月前・初日」の望遠鏡のつまみで切り替えられ、横ばいの日でも倍率を上げると景色が変わる。

**毎日触りたくなる仕掛け**
- 原因 1(直前比しかない)への直接の答え。Duolingo の「進捗が見える」を、**時間の倍率** という操作で触って確かめるものにする。つまみを回す(スワイプする)こと自体が触り心地の良い操作になる。
- 診断の上部に、横スワイプで切り替わる 4 枚の「倍率」: 昨日 / 7 日前 / 30 日前 / 初日。各倍率で、その時点に一番近いテイクと今日を比べ、横ばいの帯を描く。
- 既定の倍率は **帯の外に出た一番短い倍率** ではなく、常に「昨日」から始める(良い結果を選んで見せるのは誘導になるため)。本人が倍率を回す。
- 倍率を上げていくと、過去側の数字が遠くの星のように小さく灰色になり、今日の数字は手前に大きく残る。
- 1 日目: 倍率は「—」だけ。1 週間後: 「7 日前」が回せるようになる(つまみに目盛りが 1 つ増える瞬間を小さく祝う)。1 か月後: 「30 日前」。半年後: 「初日」が遠く小さくなるほど、今日との距離が長い。

前回との違い: 前回 D10 ノイズの帯は「今回 vs 直前」の帯だった。本案は帯を **任意の時間幅** に拡張する。前回の比較モード切替(直前 / 最も安定 / お手本)は残すが、「最も安定」は順位付けに近いので倍率の外に置く。

**ビジュアル言語**
- 色: 面 `#0E1320`(既定ダーク)/ light `#F3F5FA`、今日の白金 `#F4F1E8`(light では `#1B2233`)、過去の星の灰 `#7C8499`、帯の藍 `#26314D`(light `#DCE2EE`)、帯の外に出たときの縁取り `#7FB4FF`
- タイポ: 数字は Inter の tabular-nums で 96px(今日)/ 40px(過去)。倍率名は 20px
- 形: 円弧の目盛り(望遠鏡のつまみ)を画面下に半円で置く。帯は横長の角丸矩形
- モーション: 倍率を回すと過去の数字が奥へ遠ざかり(scale と opacity、0.3 秒)、帯の幅が今日の側で伸び縮みする。触覚フィードバック(Vibration API、短く 1 回)を目盛りごとに
- ライト/ダーク: 既定ダーク(星の比喩)、ライトも同じ構成

**情報設計とナビゲーション**
- ホーム: 今日の一本の大ボタンと、スレッドごとの小さな「最長倍率」(例: 「32 日分」)。数字は出さない。
- 診断: 上部 = 望遠鏡(倍率 × 3 項目)、下部 = 既存のピアノロール・6 指標(比較相手は選んだ倍率に追従)。
- 主導線: 開く → 録る → 診断(昨日比)→ つまみを回して 7 日前・30 日前を見る。

**主要 3 画面のスケッチ**

## D05 テイクの肖像

**一言コンセプト**: 録ったテイクは毎回、その演奏のタイミングから描かれた 1 枚の小さな模様(肖像)になり、揃って弾けた日ほど前の肖像と似てくる。

**毎日触りたくなる仕掛け**
- Duolingo の「毎回ちゃんと祝われる」「画面に生き物っぽい反応がある」を、**毎回ちがう 1 枚の模様が生まれる** に翻訳する。良くても悪くても毎回 1 枚手に入るので、録ることそのものが小さな楽しみになる。
- 肖像は各音のオンセットのズレ(拍に対する前後、または相対比較の deviation)を、円周上の花弁の長さと向きに写した生成図形。同じように弾けば同じ形になる。
- **横ばいの祝い方**: 今日の肖像を前回の肖像に重ね、重なった面積を濃く描く。横ばい(帯の中)の日は「ぴったり重なった 1 枚」として出る。一貫性の指標なので、**似ていることそのものがご褒美** になる(原因 2 への答え)。
- 1 日目: 最初の 1 枚。1 週間後: 7 枚の肖像が並び、形が落ち着いてくるのが目で分かる(または分からない。それも正直)。1 か月後: 月ごとの「重ね焼き」1 枚ができる(その月の全肖像を半透明で重ねたもの。揃っていれば輪郭がくっきり、ばらつけばぼやける)。

前回 D04 拍の時計・F4 の 1 周の詳細との違い: あれは「読むための図」で、点の重なりやラベル衝突で意味が伝わらなかった(final-result.md)。本案の肖像は **読ませない**。数字は横に別に出し、肖像はコレクションと「似ているか」を見るためだけに使う。

**ビジュアル言語**
- 色: 面 `#FAF7F2`(dark `#131313`)、今日のインク `#3057D5`(dark `#6E8CF5`)、前回の灰 `#A5A09A`(dark `#5A5752`)、重なりの濃紺 `#1C2A6B`(dark `#B9C6FF`)、紙の罫 `#E6E1D8`
- タイポ: Noto Sans JP、数字は tabular-nums。肖像の下のキャプションは日付と ms だけの 13px
- 形: 円形の肖像(直径 200px/ 一覧では 56px)。花弁は細い線で、面を塗らない
- モーション: 解析が終わると花弁が中心から 1 本ずつ伸びて(音の順に、全体で 0.8 秒)、最後に前回の灰の肖像がすっと重なる
- ライト/ダーク: 両対応。重なりの色はダークで明度を反転して選び直す

**情報設計とナビゲーション**
- ホーム: 今日の一本の大ボタン、その上にこのフレーズの最近 7 枚の肖像が 1 列。
- 診断: 上 = 今日の肖像(前回と重ね)、中 = 3 項目の数字と帯、下 = 既存の詳細。

## D06 ライナーノーツ(月ごとの 1 枚のアルバム)

**一言コンセプト**: 1 か月の練習は月末に 1 枚の「アルバム」になり、トラックはその月に弾いたフレーズ、ライナーノーツには自分の数字と自分の一言が載る。

## D07 手癖ノート

**一言コンセプト**: 診断は数字ではなく「手癖」(3 音目が早い、B♭ への押さえ替えで遅れる)の図鑑として積み上がり、癖が出なくなったものは「前は出ていた癖」のページへ移る。

**毎日触りたくなる仕掛け**
- Duolingo の「弱点の単語が見える、それが減っていく」を、ギタリストが自分で語れる **手癖** に翻訳する。「ばらつき 13ms」より「3 音目がいつも早い」の方が、次の 1 本で何を意識するかが決まる。
- 癖はフレーズ内の同じ位置(お手本/楽譜があれば音符の位置、無ければ直前テイクとのアライメント上の位置)で、同じ向きのズレが **3 テイク以上続いた** ときに初めて図鑑に載る(1 回のズレでは載せない = 断定しない)。
- 癖は消えない。直近 3 テイクで出なくなったら「前は出ていた癖」に移り、そこにいつからいつまで出ていたかの期間が残る。半年後に見返すと「前は出ていた癖」が増えていて、それが成長の手触りになる(上達とは書かない)。
- 横ばいの日も「今日は新しい癖は見つかりませんでした · 3 音目の癖は今日も出ていました」と、何かしら 1 行は書ける。
- 1 日目: 図鑑は空。1 週間後: 最初の癖が 1 つ載る。1 か月後: 1 つ目が「前は出ていた」に移るかもしれない。

前回 D07 フレーズの地層との違い: 地層は全テイクのアライメント図を描いたため重かった。本案は図ではなく **位置ごとのカウンタ**(同じ位置・同じ向きのズレが何回続いたか)だけを持つので、テイクごとの差分計算で済む。

- 形: 図鑑のページ = 左に音列の小さな帯(該当位置に印)、右に名前と期間。早い/遅いは色に加えて ◀ / ▶ の形でも区別
- モーション: 癖が「前は出ていた」に移るとき、ページが右の棚へすべって移る(0.5 秒)
- ライト/ダーク: 両対応

**情報設計とナビゲーション**
- ホーム: 今日の一本 + 「今の癖」1〜2 個のチップ(録る前に意識するもの)。

- 手癖ノート: スレッドごとに「今の癖」「前は出ていた癖」。

## D08 テンポの居場所

**一言コンセプト**: 各フレーズに「落ち着いて弾けるテンポの幅」が帯として育ち、横ばいの日は「このテンポはもう居場所」、少し上げた日は「新しいテンポを訪ねた」として描かれる。

**毎日触りたくなる仕掛け**
- ギタリストが一番よく使う成長の単位は **BPM**(♩=58 → 72)。Duolingo の「次の段が見えている」を、テンポのはしごではなく **居場所の広がり** に翻訳する。
- 各テンポで、帯の中に収まったテイク(直前と横ばい、かつ一致率が下限以上)が 3 本たまると、そのテンポは「居場所」として色が付く。横ばいが **居場所をつくる材料** になる(原因 2 への答え)。
- テンポを上げた日の結果が帯の外に大きく出ても、それは「訪ねたテンポ」として淡く残るだけで、失敗にはしない。現行 verdict.ts の「テンポを落とした回は数えない」規則を、「テンポごとに別の居場所として数える」に拡張する。
- 1 日目: ♩=58 に最初の点。1 週間後: ♩=58 が居場所になり、♩=63 に訪問の点。1 か月後: 居場所が ♩=58〜66 の帯になる。半年後: 帯の左端(遅いテンポ)も残っていて、いつ広がったかが年表として見える。

- モーション: 居場所が 1 目盛り広がるとき、琥珀の帯が目盛り 1 つ分にじむように伸びる(0.6 秒)。メトロノームの振り子が 1 回揺れる
- ライト/ダーク: 両対応

**情報設計とナビゲーション**
- ホーム: 今日の一本と、そのフレーズの居場所の帯 + 「今日のテンポ」のつまみ(既定は居場所の右端)。

- 診断: 上 = 今日のテンポでの 3 項目と帯、中 = 居場所の帯の更新、下 = 既存の詳細。

**一言コンセプト**: 1 本録るたびに、未来の自分へ一言(声でも文字でも)を残せて、その言葉は 7 日後・30 日後に同じフレーズを開いたとき、そのときの演奏と一緒に届く。

**毎日触りたくなる仕掛け**

## D10 ダブル・トラック(過去の自分たちと重ね録り)

**一言コンセプト**: 録り終えると、今日のテイクが 1 週間前・1 か月前の自分のテイクと左右に振られて同時に鳴り、揃っていれば 1 本の太い音(ダブリング)に、ずれていればフランジャーのように揺れて聞こえる。

**毎日触りたくなる仕掛け**
- ギタリストにとって一貫性の最も身体的な意味は、**重ね録り(ダブル・トラック)がきれいに重なるか**。Duolingo の「触って気持ちいい・反応がある」を、耳で気持ちいいに翻訳する。
- 一貫性は正しさではない、という芯にそのまま合う: お手本と比べなくても、自分と自分が重なれば音が太くなる。**横ばい = 太く重なった** なので、横ばいの日ほど気持ちいい(原因 2 への答え)。
- 重ねる相手は「直前」「7 日前」「30 日前」から最大 2 本。頭(最初の音のオンセット)を合わせ、tempoScale が既にあればそれで速さを合わせる。解析後、診断画面の最上段に「重ねて聴く」が大きく出る。
- 過去のテイクが増えるほど重ねられる人数が増える: 1 週間後は 2 人、1 か月後は 3 人(左・中・右)の自分とのバンド。月末には「今月の自分たち」を全部重ねたトラックも聴ける(揃っていれば合唱、ばらついていれば騒がしい。どちらも正直で、どちらも面白い)。

- モーション: 再生中、再生位置で波形が融合/分離する(オンセットのズレ量から描く。実際の波形ではなく音符の帯)。reduced-motion では静止図に再生位置の縦線だけ

**情報設計とナビゲーション**

```
│ ┌──────────────────────────┐ │
│ │ ▶ 3 人で重ねて聴く        │ │
│ └──────────────────────────┘ │
│  L 9/23 ━━━━╪━━━━━╪━━━━      │
│  今日   ━━━━━━━━━━━━━━━━━━   │
│  R 8/31 ━━┿┿━━━┿┿━━━┿┿━      │
│   (太い = 揃った、割れ = ずれ)│
│                              │
│  直前とは  横ばい  13→12ms   │
│  30 日前とは  22 → 12ms      │
│ [        もう 1 回録る      ]│
└──────────────────────────────┘
```

**体験の核**: イヤホンで「重ねて聴く」を押すと、今日の自分と 7 日前の自分が左右から同時に鳴り、ぴたりと 1 本の太い音になる瞬間。数字を見る前に耳が「揃った」と分かる。

**練習中の配慮**: 重ねて聴くのは録音後。スピーカーでも聴けるが、左右の分離はイヤホン前提なので、スピーカー時は左右ではなく「交互 → 同時」の順に再生する。再生ボタンは画面幅いっぱい。

**思想との衝突**: 「ずれて聞こえる」がはっきり分かるので、悪い日には自分の音が騒がしく聞こえてつらい。重ねるかどうかは本人の選択にし(自動再生しない)、ずれた日も「揺れて聞こえます」と中立に書く。

**リスク・弱点**: テンポの合わせ込み。メトロノーム無しのテイクは tempoScale があっても局所的なズレで序盤から割れ、ほぼ常にフランジャーになる。メトロノームありのスレッドに限定するか、相対比較のアライメントで区間ごとに頭を合わせる(重い)。音量差(録音レベル)の正規化も要る。

**実装コスト**: M〜L(Web Audio で複数 Blob の同期再生とパン、頭出しと速さ合わせ、ズレの帯表示)

## 付記: 10 案の組み合わせやすさ

- D04 時間の望遠鏡は、どの案の診断画面にも載る「比較相手の選び方」の層で、単独でも他案の部品でも使える。
- D01(聴く)と D10(重ねる)は同じ音声基盤(頭出し・同期再生)を共有する。D09 の手紙の受け取りも D01 の再生部品を使う。
- D08 テンポの居場所と D07 手癖ノートは、診断の中身を「ギタリストの言葉」に置き換える層で、D02 指板・D06 アルバムのような「積み上がる器」と組み合わせられる。
- どの案も、横ばいの判定源は verdict.ts の 1 か所に揃え、録音中には過去の自分を見せない・鳴らさない。
