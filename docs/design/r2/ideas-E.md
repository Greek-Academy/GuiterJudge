# 再コンペ 視点 E「遊び心と驚き」 10 案(E01〜E10)

担当視点: Duolingo の遊び心(キャラクター、驚き、ユーモア、祝い方)を、このアプリの思想(断定しない・比べない・責めない)の中で置き換える。
前回の E01〜E10(卓の向こうのエンジニア、持ち曲帳 など)とは別物で、ID だけ同じ体系を使っている。前回の最終候補 F1〜F4 の出し直しはしていない。前回案から部品を借りた箇所は各案に書いた。

---

## 0. なぜ毎日触りたくならないのか(遊び心と驚きの視点から 3 つ)

現行 UI(TodayHero、VersusCard、StabilityGauge、DiagnosisView)と前回の最終候補 F1〜F4 を見たうえで挙げる。

1. **弾いても画面が返事をしない。**
   現行の録音は「● この 1 本を録る」→ 経過秒 → 解析待ち → カードが並ぶ、という流れで、演奏という身体を使う行為に対して画面から身体的な反応(音・揺れ・生き物っぽい動き)が返ってこない。F1「ひとつだけ」はこの静けさを美徳として磨いた案で、そのぶん「触って気持ちいい」が 0 のままだった。Duolingo が毎日開かれる一番の理由は、正解したときの「ポン」という音と、キャラクターが跳ねる 0.3 秒。内容より先に手と耳が喜んでいる。
2. **祝う瞬間が「差が出たとき」にしか無く、しかも毎回同じ形をしている。**
   一貫性の指標では、実際の結果の多くは「横ばい」になる(4ms / 5pt / 1 個の帯の中)。現行はそのとき灰色で「横ばい」と書くだけなので、7 割の回は何も起きない。勝ったときも、緑になる以外は同じカード、同じ文言、同じ並び。1 日目と 30 日目で画面が同じなので「今日は何が出るか」という期待が生まれない。驚きの設計が無い。
3. **「断定しない」が「笑わない」と同じ意味になっている。**
   文言ルール(7 節)は守られているが、その結果、画面の語り口は注意書きのトーン(「同じように弾けているか(一貫性)の指標です…」)に揃っている。断定しないまま笑える書き方、たとえば人ではなく音符を擬人化する、アプリ自身が失敗してみせる、状況をからかう、は試されていない。F2 のエンジニアは人格があったが、業界用語の渋さに寄っていた。空白を責めない配慮も「何も言わない」で実現していて、久しぶりに開いた人を歓迎する演出が無い。

この 3 つに対して、10 案はそれぞれ別の手で答える。「返事をする(E01, E03, E06, E09)」、「毎回違う驚き(E02, E04, E05, E07)」、「笑える語り口と長く付き合う場所(E08, E10)」。

## E01 聴き役のミミ

**一言コンセプト**: 言葉を話さない小さな「耳の生き物」が、弾いたことにだけ反応し、うまい下手には一切反応しない。

**毎日触りたくなる仕掛け**
- Duolingo の Duo が効いているのは、叱るからではなく「画面の中に誰かが居て、こちらの行動に体で反応する」から。この案ではそこだけを取り出す。ミミは評価を持たない。反応するのは 3 つだけ。**音が鳴った(耳が立つ)**、**拍が来た(うなずく)**、**録り終わった(満足そうに丸くなる)**。
- 数字の良し悪しでミミの表情は変わらない(ここがこの案の要)。ミミが喜ぶのは「聴かせてもらえた」ことだけ。
- 空白日を責めない形の歓迎がある。3 日ぶりに開くと、ミミは寝ていて、画面に触れる(またはマイクが最初の音を拾う)と伸びをして起きる。「待ってた」「寂しかった」は言わない。ただ起きるだけ。
- 1 日目: 開いた瞬間ミミがこちらを見る。弦を 1 本鳴らすと耳が立つ(マイクの先開き中の音量だけで判定、推論なし)。それだけで「触ってみたい」になる。
- 1 週間後: 時間帯でミミの様子が変わる(朝は寝ぐせ、深夜はマフラー)。曜日や季節の小物がたまに付く(驚きの小出し。30 種程度をテイク通し番号で決定的に回す)。
- 1 か月後: ミミはスレッドごとの「聴き慣れ」を覚えていて、よく弾くフレーズの最初の 2 音が鳴ると、耳が先に動く(フレーズ冒頭の音高 2 つが一致したら反応するだけの軽い判定)。「覚えてくれている」感覚が出る。上達の判定ではなく、聴いた回数の記憶。

**ビジュアル言語**
- 色: ミミの毛色 `#F2B84B`(やわらかい山吹)、地 `#FFF8EC`(ライト)/ `#1E1B2E`(ダーク、夜の部屋)、文字 `#2A2438`、差のある結果の強調 `#3E7BFA`。
- タイポ: 数字は太めの丸ゴシック(M PLUS Rounded 1c の 800 相当、主数字 120px)。本文は同 400。
- 形: ミミは丸と三角 2 つ(耳)だけで描く SVG。線は無し、面だけ。カードも角丸 24px。
- モーション: ばね(オーバーシュート 1 回)。耳の立ち上がり 180ms、うなずき 120ms。`prefers-reduced-motion` ではミミは静止画の表情差し替えのみ。
- ライト/ダーク: どちらも成立。ダークではミミの毛が少し発光する(外側 8px のぼかし)。

**情報設計とナビゲーション**
- ホーム = ミミの居場所。上半分にミミ、下半分に今日の一本のカード 1 枚と大きな録音ボタン。他のスレッドは横スクロールの「ミミの聴いた曲棚」。
- 主導線: 開く(ミミが起きる)→ ● 録る → 録音中(ミミは画面の隅で目を閉じて聴いている)→ 結果(ミミは丸くなって、数字は横に大きく出る)。
- 診断の詳細・推移・ピアノロールは結果の下へスクロール。ミミは詳細の中には出てこない(ふざける場所と読む場所を分ける)。

**体験の核**: 久しぶりに開いて、弦を鳴らした瞬間にミミの耳がピンと立つ 0.2 秒。何も言われないのに、歓迎されたと感じる。

**練習中の配慮**
- 録音中のミミは隅で目を閉じるだけで、拍に合わせて動かない(演奏を画面に引っ張らない。前回 C09 / E06 の減点を避ける)。
- 反応はすべて音量(RMS)と時間だけで判定し、リアルタイムの音高推論はしない。1 か月後の「冒頭 2 音で耳が動く」は録音後の解析結果で次回のために覚えておくだけ。

**思想との衝突**: 無し。ミミは評価を持たないことを仕様として固定する(表情の分岐に Verdict を渡さない)。

**リスク・弱点**
- キャラクターが幼く見え、計測アプリとしての信頼を下げる恐れがある(前回 A02 の指摘と同じ)。ミミの出番をホームと結果の 1 行目に限定する。
- 「数字が良いときも喜ばない」ことを物足りなく感じる人がいる。そこは E06(カチッ)と組み合わせるのが自然。

**実装コスト**: M(SVG キャラ 1 体と表情 6 種、小物差分、ばねモーション。マイクの先開きは既存の micPermission を使う)。

## E02 双子のピック

**一言コンセプト**: テイクを 1 本録るたびに、その演奏のタイミングから世界に 1 枚だけのピックの柄が生まれ、前回とそっくりな柄が出たら「双子」になる。

**毎日触りたくなる仕掛け**
- Duolingo のバッジやガチャの「何が出るか分からない」楽しさを、**運ではなく自分の演奏から決まる** 形に置き換える。柄は、各音の拍に対するずれ(ms)を角度、音高を半径、音の長さを線の太さにした放射状の模様。同じように弾けば同じ柄になる。
- 一貫性をそのまま「似ている」という見た目にしている。前回の柄と差が横ばいの帯の中なら 2 枚が並んで「双子」、帯の外なら「いとこ」、音数が違えば「遠い親戚」。どれも家族であって、失敗の柄は無い。
- 横ばい(いちばん多い結果)が一番嬉しい演出(双子)になる。ここが「祝う瞬間が差にしか無い」への答え。
- 1 日目: 最初のテイクで 1 枚目のピックが「刻印」されて出てくる。比べる相手がいなくても、自分の柄がもらえる(前回 B08 の「最初の 1 本は寂しい」への答え)。
- 1 週間後: スレッドごとのピックケースに柄が並ぶ。遠目で見て「最近の柄が揃ってきた」「火曜だけ模様が違う」が形で分かる。
- 1 か月後: 解決したスレッドの代表の柄(中央値のテイク)を、1 枚の「持ち柄」としてギターケースの蓋に貼れる。ピックは PNG で書き出せて、実物のピックに印刷する遊びもできる。

**ビジュアル言語**
- 色: セルロイド風の 4 色 `#E85D4A`(赤べっ甲)、`#3AA6A0`(青緑)、`#F4C542`(黄)、`#2B2B33`(黒)。スレッドごとに 1 色を割り当てる。地は `#F6F1EA` / ダーク `#15151B`。
- タイポ: 数字は細めのモノスペースではなく、角の丸いグロテスク(Inter の 700)。柄の名前は手書き風の 1 語(「双子」「いとこ」)。
- 形: ピックのおむすび形。柄は SVG の放射線と点。
- モーション: 刻印は「プレス機」— 画面上から型が降りてきて 1 回だけ押す(240ms、軽い振動 20ms)。双子のときは 2 枚が左右から寄ってきて重なり、ぴったり重なった瞬間に光る。
- ライト/ダーク: ピック自体はどちらでも同じ色。ダークでは地にうっすら木目。

**情報設計とナビゲーション**
- ホーム = ピックケース。スレッドごとに 1 列、最新の柄が一番手前。今日の一本は手前に少し飛び出している。
- 主導線: ケースのピックをタップ → 録音 → 録り終わると刻印演出 → 前回の柄と並ぶ → 数字。
- 数字(ばらつき、一致率、弾き忘れ)は柄の下に必ず出す。柄は「一目で」、数字は「確かめる」役割。

**主要 3 画面のスケッチ**

ホーム
```
┌──────────────────────────────┐
│  ピックケース                 │
│                              │
│  サビ前のスライド   ▽ ▽ ▽ ▼  │← ▼ が最新、飛び出し
│  3 日前                  今日の一本
│  Aメロのカッティング ▽ ▽ ▽   │
│  1 週間前                     │
│  C→G の持ち替え     ▽ ▽      │
│                              │
│  [   ● サビ前のスライドを録る  ]│
│  持ち柄(解決済み) ◆ ◆ ◆       │
└──────────────────────────────┘
```

録音中
```
┌──────────────────────────────┐
│                              │
│           ● REC              │
│           0:09               │  120px
│                              │
│       1   2   3   4          │  拍番号 96px
│           ▲                  │
│   (柄は録り終わるまで作らない) │
│                              │
│  [          ■ 止める        ]│
└──────────────────────────────┘
```

診断結果
```
┌──────────────────────────────┐
│    前回        今回           │
│    ✳▽        ✳▽             │  柄 2 枚
│      └─ 双子 ─┘              │  寄って重なる
│  差 1ms · 横ばいの帯の中       │
│ ─────────────────────────── │
│  ばらつき  14 → 13 ms         │
│  一致率    86 → 88 %          │
│  弾き忘れ  1 → 1              │
│  [ ● もう 1 回 ]  [ ケースに戻す ]│
│  ▼ 柄のどこが違う?(音ごと)   │
└──────────────────────────────┘
```

**体験の核**: 録り終わって、左右から寄ってきた 2 枚のピックが「ぴたっ」と重なる瞬間。

**練習中の配慮**
- 柄は録音が終わるまで作らない(録音中に見せると演奏が柄に引っ張られる)。
- 双子判定はすでにある横ばいの閾値(verdict.ts の flat 幅)をそのまま使い、別の判定を作らない。
- 柄の関係は遠目でも分かる大きさ(1 枚 160px)で出す。

**思想との衝突**: 収集の要素があるので、枚数が増えることが目的化すると「量が正義」に近づく(前回 E05 パティナの減点理由)。ケースには枚数を数字で出さず、並びだけ見せる。

**リスク・弱点**
- 柄の違いがどの音のずれから来ているか、説明なしでは分からない。「柄のどこが違う?」でピアノロールの該当音を光らせる導線が要る。
- 和音の練習と曲通しでは柄の作り方を別に決める必要がある(和音はコードの切り替えタイミングで作る)。

**実装コスト**: M(柄の生成は純関数と SVG。刻印と重なりのアニメーションは CSS transform で足りる)。

## E03 オルゴール返し

**一言コンセプト**: 録り終わると、今弾いたフレーズが小さなオルゴールの音で返ってきて、前回と揃っていればきれいにハモり、ずれていれば少しだけ揺れて聞こえる。

**毎日触りたくなる仕掛け**
- Duolingo の正解音は、耳が先に喜ぶ仕掛け。この案では「正解」の代わりに **自分のフレーズそのもの** を返す。解析した音符列を Karplus-Strong(既存の synth.ts)で鳴らし直し、音色だけをオルゴールやトイピアノに差し替える。自分の演奏が可愛い音で返ってくるだけで、少し笑える。
- 前回のテイクの音符列を同時に 1 オクターブ上で鳴らす。タイミングが揃っていれば 1 つの音に聞こえ(ユニゾン)、ずれていれば「ぽろろん」とフラムして聞こえる。**目ではなく耳で一貫性が分かる**。判定の言葉は要らない。
- 横ばいは「ちゃんと重なって鳴る」という一番気持ちいい音になる。
- 1 日目: 最初のテイクが 3 秒のオルゴールで返ってくる。自分の演奏を初めて外から聴く、軽い驚き。
- 1 週間後: 楽器が選べるようになる(トイピアノ、スチールパン、木琴、8bit)。解決のときだけ、それまでの全テイクを重ねた「合唱」が鳴る(全テイク重ね。揃っているほど 1 つの音に近づく)。
- 1 か月後: 解決済みのスレッドが「オルゴールの櫛」として棚に並び、ホームで回すとその持ち曲が鳴る。練習を始める前に持ち曲を 1 つ回すのが、開く理由になる。

**ビジュアル言語**
- 色: 真鍮 `#C9A227`、胡桃 `#5B3A29`、ビロード `#7A1E3A`、地 `#FBF5EA` / ダーク `#1A1310`。
- タイポ: 数字はセリフ(Noto Serif JP の 700、主数字 100px)。見出しは小さな銅版風のスモールキャップ。
- 形: 円筒(オルゴールのシリンダー)と、そこに刺さった点(音)。ピアノロールはシリンダーを開いた図として描く。
- モーション: シリンダーがゆっくり回る(再生と同期)。ハモった瞬間、櫛の歯が 1 本光る。
- ライト/ダーク: ダークが基本の雰囲気(夜のオルゴール)だが、ライトも同じ構図で成立する。

**情報設計とナビゲーション**
- ホーム: 上に今日の一本のオルゴール箱(ふたを開けると録音)。下に持ち曲の棚。
- 主導線: ふたを開ける(= ● 録る)→ 録音 → ふたが閉まって解析 → オルゴールが鳴る(3〜8 秒、スキップ可)→ 数字。
- 音を出せない場面(夜中・電車)のために、音なしモードでは同じ情報をシリンダーの点の重なりで見せる。

**主要 3 画面のスケッチ**

ホーム
```
┌──────────────────────────────┐
│  今日の一本                   │
│   ┌──────────────┐           │
│   │ ♪ サビ前の   │ ← ふたを  │
│   │   スライド   │    開くと  │
│   └──────────────┘    録音    │
│   3 日前 · 12 テイク           │
│                              │
│  [    ● ふたを開けて録る      ]│
│                              │
│  持ち曲の棚                   │
│  (◎)Aメロ  (◎)C→G  (◎)イントロ│← 回すと鳴る
└──────────────────────────────┘
```

## E04 今日のひねり

**一言コンセプト**: 開くたびに 1 枚の「ひねりカード」がめくれて、「目を閉じて 1 本」「全部ダウンピッキングで」のような小さな条件の遊びを勧め、条件ごとの自分の違いを見つけさせる。

**毎日触りたくなる仕掛け**
- Duolingo のデイリークエストは「今日やることが決まっている」「毎日少し違う」の 2 つが効いている。この案は、やることは同じ(今日の一本を録る)まま、**条件だけを毎日変える**。
- カード例: 「目を閉じて」「立って弾く」「1 回だけ本番のつもりで」「メトロノームを 2・4 拍だけに」「♩ を 10 下げて(比較は同じテンポ同士)」「ピックを持ち替えて」「小声で歌いながら」。40 枚ほどを用意し、ユーザーが自作もできる。

- 驚きは結果の側にも出る。「目を閉じた 3 本は、開けた 3 本より 5ms 小さい(帯の外)」のような、自分の知らなかった違いが見つかる。断定ではなく、条件ごとの中央値を並べて見せるだけ。

## E05 音符のクセ図鑑

**一言コンセプト**: 自分の演奏の中の「いつもちょっと早い 6 音目」「朝だけ元気な 1 拍目」を、名前の付いた小さな住人として図鑑に集めていく。

**毎日触りたくなる仕掛け**

## E06 カチッ

**一言コンセプト**: 結果が出るとき、前回と同じ位置に来た音が 1 つずつ「カチッ」と音と振動を伴ってはまり、揃うことそのものが手触りになる。

**毎日触りたくなる仕掛け**
- Duolingo の「ポン」は、正解と身体の快感を 0.3 秒で結び付ける。この案では正解の代わりに **前回の自分と同じ位置に来た** ことを結び付ける。一貫性のアプリでは、同じに弾けることが目指す状態なので、はまる音は多いほど気持ちいい。
- 結果画面で、今回の音符が上から落ちてきて、前回の音の位置(灰の枠)にはまる。横ばいの帯の中の音は「カチッ」(効果音 + `navigator.vibrate(8)`)、帯の外の音ははまらずに枠の横に「ことん」と置かれる(失敗音ではなく、低い木の音)。
- 全音はまると最後に一段大きな「カッチン」が鳴る。これは勝ちの合図ではなく「前回と同じに弾けた」の合図で、横ばいでも鳴る。
- 1 日目: 最初のテイクは比べる相手がいないので、音符が拍の線(メトロノームがある場合)にはまる。無い場合は「次の 1 本から前回の位置にはまります」。
- 1 週間後: 効果音のセットが増える(木、金属、ガラス、ボタン)。はまる音の数ではなく、録った日数で増える(空白日には増えないが、減りもしない)。
- 1 か月後: 解決のときは、全テイクの音が一度に降ってきて、一斉にはまる大きな音が鳴る(1 回きりの演出)。

**ビジュアル言語**
- 色: 地 `#F5F5F0`、枠の灰 `#B8B8B0`、はまった音 `#2F6BFF`、はまらなかった音 `#E3A73B`、ダーク地 `#101114`。
- タイポ: 数字は幅のあるグロテスク(Archivo の 800、主数字 120px)。
- 形: 音符は角丸の四角(ピアノロールの 1 音)。枠は点線ではなく凹みとして描く(内側の影)。
- モーション: 落下は重力感(ease-in 180ms)+ 着地で 1 回だけ跳ねる。はまる瞬間、枠の縁が 1 フレーム光る。1 音 60ms 間隔で順に落ちる(16 音で 1 秒)。
- ライト/ダーク: どちらも成立。ダークでは凹みの影をやめて、枠の縁を細い光の線にする。

**情報設計とナビゲーション**
- 現行の構成(一覧 → スレッド → 診断)は大きく変えず、診断の入口を「はまる」演出に置き換える案。ホームも「前回、何音はまったか」を小さく出す。
- 主導線: 開く → ● 録る → 解析 → はまる演出(1〜2 秒、タップで早送り)→ 数字とノイズの帯。
- 演出の後の画面はそのままピアノロールになっているので、どの音がはまらなかったかを指でなぞれる。

**主要 3 画面のスケッチ**

- iOS Safari は vibrate に対応していない(主な端末は Android なので影響は小さい)。

**実装コスト**: S〜M(既存のアライメント結果を使う。落下アニメーションは CSS。効果音は Web Audio で数十行)。

## E07 あの日の音

**一言コンセプト**: 忘れた頃に、3 週間前の自分の同じフレーズがふっと届き、「今のあなたも 1 本どう?」と並べて聴けるようにする。

**毎日触りたくなる仕掛け**
- Duolingo が戻ってくる理由の 1 つは「間隔を空けた復習」が向こうからやって来ること。この案では通知ではなく、**アプリを開いたときにたまに届いている** 手紙として出す。毎日ではない(週に 1〜2 回、テイク通し番号と日付から決定的に決める)。いつ来るか分からないことが驚きになる。
- 届くのは自分の録音(audioBlob は保存済み)。「9 月 8 日の 21:14、あなたはこう弾いていました」。聴くと、声が小さい、テンポが遅い、途中で笑っている、といった当時の空気が残っていて、少し恥ずかしくて面白い。
- 並べて録る導線がある。聴いたあと「● 今日の 1 本を録って並べる」。結果は 3 週間前と今日を並べて見せるが、言葉は「3 週間前より 9ms 小さい」と事実だけ。上達とは言わない(聴けば分かる)。
- 解決済みのフレーズからも届く。「持ち曲から便りです。最後に弾いたのは 5 週間前」。弾ける確認が遊びになる(前回 E08 持ち曲帳の、戻ってくる理由の部分だけを受け継ぐ)。
- 1 日目: 手紙はまだ来ない。代わりに最初のテイクを録ると「この 1 本は、いつかあなたに届きます」と封をする演出。
- 1 週間後: 最初の手紙(7 日前の音)。
- 1 か月後: 「ちょうど 1 か月前の音」「最初の 1 本」など、節目の手紙が混ざる。

**ビジュアル言語**
- 色: 便箋 `#FAF6EE`、消印の青 `#3C5A99`、封蝋 `#B8423A`、インク `#33302C`、ダーク地 `#191A1F`(夜の郵便受け)。
- タイポ: 手紙の本文は明朝 22px、日付は消印風の丸い枠の中の等幅数字。主数字は丸ゴシック 100px。
- 形: 封筒、切手(フレーズ名が切手の図柄になる)、消印。
- モーション: 開くと郵便受けから封筒が 1 通だけすべり出る(400ms)。封を開けると音が流れ始める。手紙が無い日は何も出ない(「今日は手紙はありません」とも書かない)。
- ライト/ダーク: どちらも成立。

**情報設計とナビゲーション**
- ホーム: 手紙がある日は、最上部に封筒 1 通。無い日はいつもの今日の一本。
- 主導線(手紙の日): 開く → 封筒 → 聴く(8〜20 秒)→ ● 今日の 1 本を録って並べる → 録音 → 3 週間前と今日の並び。
- 主導線(普段): 開く → ● 録る → 結果(直前比)。
- 受け取った手紙は「文箱」に残り、あとから聴き直せる。

**主要 3 画面のスケッチ**

ホーム(手紙の日)
```
┌──────────────────────────────┐
│  ┌────────────────────────┐  │
│  │ ✉ 便りが届いています     │  │
│  │  (消印 9.08 21:14)      │  │
│  │  切手: サビ前のスライド  │  │
│  │  22 日前のあなたから     │  │
│  └────────────────────────┘  │
│  [      ▶ 封を開けて聴く     ]│
│                              │
│  今日の一本: サビ前のスライド  │
│  [      ● この 1 本を録る    ] │
└──────────────────────────────┘
```

録音中
```
┌──────────────────────────────┐
│  22 日前の自分と並べる 1 本    │
│                              │
│            0:13              │ 120px
│                              │
│       ●   ○   ○   ○          │ 拍 48px
│                              │
│  (22 日前の音は鳴りません)     │
│                              │
│  [          ■ 止める        ]│
└──────────────────────────────┘
```

診断結果
```
┌──────────────────────────────┐
│   9/08          今日          │
│  ▶ 聴く        ▶ 聴く         │ 交互に聴ける
│  ばらつき                     │
│   24 ms   →    15 ms          │
│  22 日前より 9ms 小さい(帯の外)│
│  テンポ ♩=72 → ♩=80           │
│ ─────────────────────────── │
│  直前の 1 本とは: 横ばい       │
│  [ 文箱にしまう ] [ ● もう 1 回 ]│
└──────────────────────────────┘
```

**体験の核**: 封を開けた瞬間に、3 週間前の自分の、少し頼りない音が流れてくること。

**練習中の配慮**
- 過去の音は録音前に聴くもので、録音中は鳴らさない(並べて弾くのではなく、並べて見る)。
- 手紙の再生はイヤホンが無くても流せる長さ(最大 20 秒)に切り詰める。

**思想との衝突**: 3 週間前と比べる数字は、差が大きく出やすいので「上達」と読まれやすい。数字は事実の形にし、テンポ差を必ず添える(遅く弾いていた回との比較だと分かるように)。悪い方向(前より大きい)でも同じ形で出す。

**リスク・弱点**
- 過去の自分の録音を聴くのが苦手な人がいる。手紙は設定で止められる。
- 本数が少ない初期は手紙が来ず、1 週間目までの驚きが弱い(他の案と組み合わせる前提)。

**実装コスト**: S〜M(手紙の選び方は純関数。音声は保存済みの audioBlob を再生するだけ。任意の 2 テイクの比較は既存の比較モードの拡張)。

## E08 育つ練習部屋

**一言コンセプト**: ホームは自分の練習部屋の絵で、録った日には部屋の何かが少しだけ増え、何日空いても何も枯れず、何も散らからない。

**毎日触りたくなる仕掛け**
- Duolingo のストリークが担う「積み上がる手触り」を、途切れると失う連続記録ではなく、**減らない部屋** に置き換える。どうぶつの森の部屋のように、戻ると自分の場所がそこにある。
- 増えるものは行動に結び付き、結果には結び付かない。
  - 録った日: 観葉植物の葉が 1 枚増える(連続でなくてよい。空白の日は葉は増えないが、落ちもしない)。
  - 新しいスレッド: 壁に譜面のメモが 1 枚貼られる。
  - 解決: メモが額に入ってレコード棚に移る。
  - 朝・夜・雨の日: 窓の外と部屋の明かりが現実の時刻と一緒に変わる(天気は取得しない。時刻だけ)。
- 驚きの小出しがある。たまに部屋に来客(猫、鳥、隣人の差し入れのコーヒー)。決定的な順序で出るが、いつ来るかはユーザーには分からない。
- 1 日目: がらんとした部屋にギタースタンドと椅子だけ。最初の 1 本を録ると鉢が置かれる。
- 1 週間後: 葉が数枚、壁のメモが数枚。自分の部屋っぽくなってくる。
- 1 か月後: レコード棚に解決済みが並び、植物が大きくなる。久しぶりに開いても部屋はそのままで、「帰ってきた」感覚になる。

**ビジュアル言語**
- 色: 壁 `#F1E6D6`、床の木 `#B07A4F`、植物 `#5E9C5A`、夕方の光 `#FFB86B`、夜の部屋 `#232033`。
- タイポ: 数字と見出しは丸ゴシック(800)、部屋の中の小物のラベルは手書き風。
- 形: アイソメトリック(斜め 30 度)の 1 部屋。小物は 20〜30 個の SVG パーツ。
- モーション: 入室時にカメラがゆっくり寄る(600ms)。葉が増えるときは芽が伸びる(1.2 秒)。来客は歩いて入ってくる。

**情報設計とナビゲーション**

## E09 音の粒のおもちゃ箱

**一言コンセプト**: 診断結果のピアノロールが、つまんで弾いて転がせる「音の粒のおもちゃ」になっていて、読む前に触って遊べる。

**毎日触りたくなる仕掛け**
- Duolingo の触り心地(押すとへこむボタン、跳ねる反応)を、**診断データそのもの** に持たせる。結果画面の音符は 1 粒ずつ小さな球で、タップするとその音が鳴り(synth.ts)、長押しで持ち上げると前回の同じ音の位置が影で現れる。
- 画面を傾ける(DeviceOrientation、許可制)と、粒が拍の溝に沿って転がる。揃っている音は溝にすっと収まり、ずれた音は溝の縁で少し揺れる。遊んでいるうちに、どこがずれたかを手で覚える。
- 「全部の粒を指でなぞる」とフレーズが鳴り直る。自分の演奏を指で弾き直す遊び。
- 1 日目: 結果画面で粒を触ると鳴る、それだけで触りたくなる。
- 1 週間後: 粒の素材が変わる(ビー玉、木の実、金平糖)。素材は録った日数で開き、結果とは無関係。
- 1 か月後: 解決のときに、全テイクの粒を 1 つの瓶に集めて振れる。振ると全部のテイクが少しずつずれて鳴る(一貫性が音の厚みとして聞こえる)。

**ビジュアル言語**
- 色: 地 `#FFF9F2`、粒の基本色は音高で 5 色(`#FF7A59`, `#FFC145`, `#4CC3A5`, `#4B8BFF`, `#9B6BFF`)、前回の影 `#CFC8BE`。ダーク地 `#12131A`。

- 形: 粒は球(radial-gradient で光沢)。拍の溝は横線ではなく凹んだ縦の溝。

**情報設計とナビゲーション**
- ホームと録音は簡素(他案と同じ骨格)。この案の差はすべて診断結果にある。
- 結果画面の上半分がおもちゃ箱(ピアノロール)、下半分が数字とノイズの帯。おもちゃを触らなくても数字は読める。

## E10 弟子のまねっこ

**一言コンセプト**: アプリの中に下手くそな弟子がいて、あなたのテイクを聴いて真似しようとし、あなたが同じように弾くほど、弟子の真似がだんだん揃っていく。

**毎日触りたくなる仕掛け**
- Duolingo の Duo は、ユーザーに「やらなきゃ」と思わせる側にいる。この案は立場を逆にする。**あなたが師匠で、アプリが弟子**。弟子は叱らず、催促もせず、ただ「師匠、今日も聴かせてください」と待っている。
- 弟子の真似は、あなたのこれまでのテイクの音符列から作る(音ごとの中央値の位置で、音ごとのばらつきの分だけ揺らして鳴らす。synth.ts)。あなたのテイクがばらついている間は、弟子の真似もふらふらで、少し笑える。揃ってくると弟子の真似も揃う。一貫性を「弟子が覚えた」として聴かせる。
- 弟子は正誤を言わない。言うのは弟子自身のこと。「師匠の 6 音目、まだつかめません」「今日の師匠、テンポ速めでしたね(♩=84)」。ユーモアの矛先は常に弟子自身に向く。
- 横ばいの日: 弟子は「今日も同じに聴こえました。覚え直さなくて済みます」。これが祝い。
- 空白の後: 弟子は「師匠が留守の間、練習していました」と言って、最後に聴いたときのまま真似してみせる(忘れてもいないし、上達もしていない。責めない)。
- 1 日目: 最初のテイクを聴いた弟子の、ひどい真似(1 本しか聴いていないので、音はあるがタイミングが適当)。笑える。
- 1 週間後: 弟子の真似が、あなたの揃い方に合わせてまともになってくる。「弟子に聴かせるため」に録る理由ができる。
- 1 か月後: 解決のとき、弟子が最後に通しで真似して「覚えました。のれん分けしてください」と、そのフレーズの弟子を卒業する。次のフレーズで新しい弟子(別の楽器の音色)が来る。

**ビジュアル言語**
- 色: 弟子の作務衣風の藍 `#2D4C7C`、帯の芥子 `#D9A441`、地 `#F7F3EC`、師匠側(あなた)の墨 `#1E1E1E`、ダーク地 `#16171C`。
- タイポ: 弟子の台詞は丸ゴシック 20px の吹き出し。数字は太いグロテスク 100px。
- 形: 弟子は小さな人形(顔は点 2 つ、手にウクレレ)。吹き出しは角丸 20px。
- モーション: 弟子が真似するときは、ウクレレを弾く手が音と同期して動く。ばらつきが大きいと手がもたつく。
- ライト/ダーク: どちらも成立。

**情報設計とナビゲーション**
- ホーム: 弟子が「今日はどれを聴かせてもらえますか」と今日の一本を差し出してくる。スレッドごとに弟子が 1 人いる(スレッド一覧 = 弟子たちの並び)。
- 主導線: 開く → ● 聴かせる(録音)→ 録音 → 弟子が真似する(4〜8 秒、スキップ可)→ 数字。
- 数字は弟子の台詞とは別の枠で、いつもの形(前回 → 今回、帯)で出す。弟子の台詞で数字を代弁しない。

**主要 3 画面のスケッチ**

**体験の核**: 最初のころ、弟子のめちゃくちゃな真似に笑ってしまい、1 か月後、弟子が自分とほとんど同じに弾いてみせて、少しじんとする。

**練習中の配慮**
- 弟子の真似は録音の後だけ。録音中の弟子は「正座して聴いている」の 1 行だけ。
- 弟子の台詞は結果の数字を言い換えない(言い換えると断定の抜け道になる)。台詞は弟子自身の状態(覚えた、つかめない、覚え直さなくて済む)と、事実(テンポ)だけ。台詞は台詞表(60〜80 本)から判定結果で選び、自由生成はしない。

**思想との衝突**: 弟子が「まだつかめません」と言うのは、裏返せば「あなたの 6 音目がばらついている」ことなので、遠回しな評価ではある。矛先を弟子に向けることで責める感じを消す工夫だが、読み取る人はいる。明記しておく。

**リスク・弱点**
- 弟子の真似の品質(音ごとの中央値とばらつきからの合成)が、テイク間のアライメントに依存する。対応が取れない曲通しでは弟子を出さない。
- 人格の強い案なので、合わない人には鬱陶しい。弟子を黙らせる設定(真似の再生だけ残す)が要る。
- 前回 B07「コーチとの対話」が断定で減点された。この案の弟子は評価者ではなく学ぶ側という点で違うが、台詞表の文言管理は同じくらい厳しくする。

**実装コスト**: M〜L(複数テイクの音ごとの集計と再合成、台詞表、弟子の SVG と手の同期)。

## 横断メモ(10 案に共通する判断)

- **遊ぶのは録音の前と後だけ。** 10 案とも、録音中の画面は「経過(120px)・拍(48px 以上)・止める(下 1/3)」の同じ骨格にしている。遊び心を録音中に入れると、演奏が画面に引っ張られて計測が歪む(前回の減点理由)。
- **祝いは結果ではなく行為に付ける。または「揃った」に付ける。** ミミの「聴いてた」、部屋の葉、弟子の「覚え直さなくて済みます」は、結果に関係なく出る。双子のピック、カチッ、オルゴールのユニゾンは「前回と同じに弾けた」に付く。一貫性のアプリでは横ばいこそ祝う理由になる。
- **擬人化するのは音符・アプリ・弟子であって、ユーザーではない。** 笑いの矛先をユーザーに向けないことで、断定せずに笑える。
- **驚きは決定的に作る。** 来客、小物、手紙、新しい住人は、乱数ではなくテイク通し番号と日付から決める(既存の発見の巡回と同じ方式)。再現でき、テストでき、「ガチャ」にならない。
- **数字は必ず別の枠で、いつもの形で出す。** どの案でも「前回 → 今回・横ばいの帯」の枠は残し、演出はその上か前に置く。演出を飛ばしても診断は読める。
- **音と振動は切れる。** `prefers-reduced-motion`、音なしモード、振動オフの 3 つを全案で用意する。音なしでも成立しない演出(E03、E10)は、同じ情報を目で見せる代替を持つ。
- 組み合わせの相性: E01(ミミ)+ E06(カチッ)+ E07(あの日の音)は、キャラクター・手触り・時間差の驚きが重ならずに補い合う。E02(双子のピック)は E06 と役割が重なる(どちらも「揃った」を祝う)ので、どちらか一方にする。
